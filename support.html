How Bingo works in one line

Bingo draws your task list as an image. iOS lets no app set the wallpaper itself, so a shortcut on your device does that last step. That is why the shortcuts are not optional.

Setting it up the first time

  • Open Bingo and let the welcome screens install all three shortcuts. Each one opens the Shortcuts app, where you tap to confirm. Install all three — the third one is what the "Apply to Lock Screen" button in the app runs.
  • Then put the two buttons on your Lock Screen: long-press the Lock Screen → Customize → Lock Screen → remove the flashlight and camera → add Bingo-select (check off) and Bingo-add (add a task).
  • You can skip the Lock Screen buttons entirely and just use the "Apply to Lock Screen" button inside the app whenever you want to refresh the wallpaper.

"Apply to Lock Screen" does nothing

That button runs the Bingo-refresh shortcut by name. It fails silently if the shortcut isn't installed, or if it was renamed or deleted. Go to Settings → Lock Screen setup inside the app and install it again, and don't rename it in the Shortcuts app.

The wallpaper isn't updating

  • The wallpaper is not live — it only changes when a shortcut runs. Tap "Apply to Lock Screen", or use one of the Lock Screen buttons.
  • Check the shortcut's "Set Wallpaper" action: "Show Preview" should be off, and only Lock Screen should be ticked.
  • If a shortcut's install link won't open, its iCloud signature may have expired. Update the App, or email us and we'll publish fresh links.
  • Tapping a Lock Screen button asks you to unlock first. That's how iOS handles shortcuts that run app actions; it's not something the App can bypass.

Tasks are missing, or too many to fit

  • Bingo shows one list at a time. Pick which one in Settings.
  • Using Apple Reminders as storage requires the Reminders permission. If you declined it, grant it in iOS Settings → Privacy & Security → Reminders → Bingo, or switch to on-device storage in the app's Settings.
  • When there are more tasks than fit on the screen, the wallpaper ends with "and N more…". Adjust card position and bottom spacing on the Lock Screen tab to fit a few more lines.
