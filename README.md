# bingo-legal

Legal and support pages for **Bingo!**, the iOS Lock Screen checklist app.

Published with GitHub Pages at <https://by123.github.io/bingo-legal/>

| Page | URL |
|---|---|
| Privacy Policy | https://by123.github.io/bingo-legal/privacy-policy.html |
| Terms of Service | https://by123.github.io/bingo-legal/terms-of-service.html |
| Support | https://by123.github.io/bingo-legal/support.html |

These are the URLs filled into `Sources/Support/SupportLinks.swift` in the app,
and the ones to enter in App Store Connect (Privacy Policy URL and Support URL
are both required fields).

Plain static HTML — edit the files and push; Pages rebuilds on its own.
